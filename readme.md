# Using Canva AI to Adapt Brand Voice Across Communications  

## Objective  
Demonstrate how Canva AI (Magic Write) can generate and adapt communication content across different brand voices, while supporting a simple, accessible workflow focused on content rather than design.

---

## Tools Used  
- Canva Docs (Magic Write)  
- AI prompting and editing  

---

## Workflow  
1. Created a single prompt for a social media announcement  
2. Applied the prompt across multiple brands  
3. Reviewed and lightly edited outputs for tone and clarity  
4. (Optional) Adapted one output into a simple visual format  

---

## Prompt Used  
“Write a short social media post announcing a new initiative in the tone of [brand name]. Keep it concise and audience-friendly.”

## Key Insight  
Canva AI can quickly generate content tailored to different brand voices using a single prompt, enabling communications teams to scale messaging efficiently while maintaining tone consistency.

---

## Accessibility Considerations  
Canva’s interface has known accessibility limitations with screen readers such as NVDA. Many toolbars and menus are not fully navigable, which can make layout and design features difficult to access. To address this, the workflow focused on **AI-generated content and prompt design**, rather than heavy visual editing. This demonstrates how AI tools can still support communications workflows even in environments where accessibility is a concern.
